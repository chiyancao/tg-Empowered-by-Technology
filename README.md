# 服务器被偷偷登录？这款SSH通知脚本，帮你守住大门！

对运维和开发者来说，服务器安全就像守家门——你永远不知道，会不会有人悄悄“撬锁”登录。

想象一下：你正摸鱼喝咖啡，手机突然弹出一条提醒：“ROOT用户从陌生IP登录你的服务器！” 这种实时掌控的安全感，全靠今天要给大家安利的神器——SSH登录通知脚本。

# 一、这脚本到底能帮你做什么？

这款SSH登录通知系统（v2.6）是开源免费工具，核心作用就一个：**实时监控服务器SSH登录行为，有动静立刻通过手机通知你**，相当于给服务器装了个“智能门禁报警器”。

## ✨ 5大核心功能，普通人也能看懂

### 1. 🚨 登录动静秒通知，重点情况标红提醒

- 普通用户登录：日常提醒，知晓谁在操作

- ROOT用户登录：高优先级警告（ROOT权限最大，风险最高）

- 登录失败尝试：实时拦截暴力破解苗头

### 2. 📍 自动定位登录IP，陌生地址一眼辨

不用手动查IP归属，脚本会自动识别位置，比如：

IP: 203.0.113.100

地理位置: 中国, 北京, 北京 (中国电信)

要是显示异地陌生地址，就能第一时间排查是否是恶意登录。

### 3. 📊 附带系统状态，登录同时摸清服务器情况

每次登录通知都会同步这些信息，不用额外登录查看：

- CPU、内存、磁盘用了多少

- 当前还有哪些人在线

- SSH连接数、服务器运行了多久

### 4. 👥 在线用户一目了然，谁在操作全掌握

通知里会清晰列出所有在线用户，比如：

当前在线用户 (共 3 人)

- admin (192.168.1.100) - 14:30登录

- user1 (60.191.47.66) - 14:25登录

- root (本地) - 14:20登录

### 5. 📋 历史登录记录，异常模式早发现

自动展示最近5次登录记录，方便你排查是否有规律的恶意登录尝试。

# 五、进阶玩法：按需自定义，更贴合需求

## 🔧 自定义通知内容（开关自由）

配置文件在 /etc/ssh-notify/config.conf，可手动调整开关：

ENABLE_LOGIN_SUCCESS=true  # 开启成功登录通知（必开）

ENABLE_LOGIN_FAILURE=true  # 开启失败登录通知（防爆破）

ENABLE_GEO_IP=true        # 开启IP地理位置识别

ENABLE_SYSTEM_INFO=true   # 显示系统状态信息

## 📝 日志管理：排查问题有依据

日常可通过日志监控登录情况，常用命令：

tail -f /var/log/ssh-notify.log  # 实时查看日志

grep "失败" /var/log/ssh-notify.log  # 搜索登录失败记录

## 🧪 手动测试：确保通知正常

支持模拟各种场景测试，比如普通用户登录、ROOT登录、失败登录，确认通知能正常接收。

# 九、常见问题排查（避坑指南）

❓ 收不到通知怎么办？

答：先检查Gotify服务器是否正常，再用脚本菜单【4】测试通知发送，排查配置是否正确。

❓ 通知有延迟？

答：大概率是网络波动，可检查服务器网络连接，调整超时设置。

❓ 想修改通知内容？

答：编辑 /etc/ssh-notify/notify.sh 文件，按需调整通知文案和展示信息。
